# Hide & Seek 3D + New App Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Popo's 2D Vietnamese UI with a three.js, English, party-game shell and a complete 3D Hide & Seek, keeping the server-authoritative rules and network protocol.

**Architecture:** Server keeps rules; it gains bigger maps, body collision, obstacle blocking, ground-plane hit tests, 24 avatars and a lobby `ready` flag. The browser becomes one ES-module app (`public/app.js`) with a shared three.js engine (`public/core3d/`) and the game client (`public/games/hideseek3d/`). Kenney CC0 GLB models live in `public/assets/kenney/`.

**Tech Stack:** Node ≥18 + `ws` (server), `node:test` (unit tests), three.js 0.160.0 via importmap from jsdelivr, GLTFLoader, Lilita One font. No build step.

**Spec:** `docs/superpowers/specs/2026-11-04-hide-seek-3d-design.md` (sections 1–9; section 9 overrides earlier numbers).

## Global Constraints
- All visible copy is English; font Lilita One; ink `#24304a`; 12 player colors in spec §2 order.
- 1 three.js unit = 100 server units; server `x` → 3D `x`, server `y` → 3D `z`.
- Animal codes 0–23 are the spec §2 table, defined once in `public/core3d/animals.js` (UMD, `require`-able by server).
- Only `hideseek` is registered in `server/index.js`; drive/badminton files stay untouched.
- Deploy unchanged: `npm start`, no bundler. three.js `0.160.0` exact.
- Mobile (`pointer: coarse`): no shadows, pixelRatio ≤ 1.5. Desktop pixelRatio ≤ 2. Auto-drop to 1 if < 40 fps for 3 s.
- Rules values not listed in spec §4/§9 stay as in current `server/games/hideseek/index.js`.

## Review Focus
1. Seeker must never learn which entity is a hider: hider rings/tags/`mates` never render on a living seeker's client — test in Task 8 (render state check with seeker snapshot).
2. Rejoin mid-round rebuilds the scene from `init` + next `s` without duplicate meshes — test in Task 8 (call `init` twice, count entities).
3. Shooting at a point beyond `RANGE` or with NaN coordinates must not crash or hit — test in Task 3.
4. Animals pushed by collision must never end inside a pond/building/sea or outside map bounds — test in Task 3.
5. Lobby with 12 players on a 375×812 screen keeps every name tag on screen and non-overlapping with own pedestal — checked in Task 6 browser verification.
